# 🩺 HealMate AI — Smart Healthcare Chatbot

🌍 **AI-powered multilingual health assistant supporting UN SDG 3 (Good Health & Well-being)**

---

## 🧠 Overview

**HealMate AI** is a smart healthcare chatbot built using **HTML, CSS, and JavaScript**, powered by the **Google Gemini API**.

It provides **real-time health information, medical awareness, and virtual assistance** through both **text and voice**, supporting multiple Indian languages.

This project promotes **United Nations SDG 3 (Good Health & Well-being)** by making healthcare knowledge **accessible, inclusive, and affordable**, especially for people in remote areas.

---

## 💡 Key Features

* ✅ **AI-Powered Health Chat**
  Ask health-related questions and receive instant AI-generated responses.

* 🌐 **Multilingual Support**
  Supports **English, Hindi, Kannada, Telugu, and Tamil**.

* 🎤 **Voice Assistant**

  * Speech-to-text (microphone input)
  * Text-to-speech (AI voice response)

* 🔄 **Chat Reset & Language Switch**
  Clear chat instantly or switch languages with dynamic greetings.

* 🎨 **Modern Neon UI**
  Responsive design with smooth animations and chatbot interface.

* 🤖 **Gemini API Integration**
  Uses Google Generative AI for contextual and intelligent responses.

## 🏗️ Architecture Overview

```id="arch1"
User 
  ↓
UI (HTML, CSS, JS)
  ↓
Speech Recognition (Mic Input)
  ↓
Chat Interface (Text Display)
  ↓
Language Selector
  ↓
Gemini API (Google Generative AI)
  ↓
AI Processes Health Queries
  ↓
Response Returned
  ↓
Text-to-Speech (Voice Output)
```
